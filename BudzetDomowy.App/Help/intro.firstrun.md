# Pierwsze uruchomienie

Przy pierwszym uruchomieniu pojawia się kreator.

![Kreator pierwszego uruchomienia (przykład).](first-run.png)

1. **Folder danych**: wskaż folder w OneDrive (np. `BudzetDomowy_dane`). Aby dwie osoby pracowały na tych samych danych, obie wskazują ten sam, udostępniony folder. Przycisk **Przeglądaj…** otwiera okno wyboru folderu. Kreator sprawdza folder: czy można w nim zapisywać i czy pliki nie są tylko w chmurze.
2. **Nazwa komputera**: pomaga odróżnić urządzenia na ekranie synchronizacji (np. „Komputer Ani”).
3. **Zakończ**: program wczyta istniejące dane z folderu i przygotuje domyślne kategorie, jeśli nikt jeszcze ich nie utworzył.

Folder danych można później zmienić: [Ustawienia → Ogólne](settings.general).
