# Wydatki cykliczne

Szablony wpisów, które **powtarzają się same**: czynsz, abonament, pensja. Program tworzy z nich zwykłe wpisy, gdy nadejdzie termin.

![Ekran Wydatki cykliczne (przykład).](recurring.png)

- Po lewej lista szablonów (nazwa, kwota, kiedy się powtarza i kiedy ostatnio wygenerowano). Po prawej szczegóły wybranego.
- **Nowy wpis cykliczny** tworzy szablon; **Utwórz zaległe teraz** od razu tworzy wpisy, których termin już minął. Poza tym program robi to sam przy starcie.
- Dwa komputery nie utworzą podwójnych wpisów.
