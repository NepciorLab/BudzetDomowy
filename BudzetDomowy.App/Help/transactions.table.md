# Tabela wpisów

Kolumny: **Data**, **Rodzaj**, **Kwota** (w złotych), **W walucie** (kwota i kurs, jeśli wpis jest w innej walucie niż PLN), **Kategoria**, **Miejsce**, **Notatka**, **Wydarzenie**.

- Kliknięcie nagłówka **sortuje** tabelę, drugie kliknięcie odwraca kolejność.
- **Prawy przycisk na nagłówku** pozwala wybrać, które kolumny są widoczne (wybór jest pamiętany osobno dla każdej tabeli).
- `Home` i `End` przechodzą do pierwszego i ostatniego wpisu.
- Szerokość kolumn można dopasować automatycznie: [Ustawienia → Ogólne](settings.general).
